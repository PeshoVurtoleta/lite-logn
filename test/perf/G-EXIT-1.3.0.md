## S7k budget (maintainer amendment)

k is computed PER (lane, KIND) from the values that ACTUALLY cross the boundary, NOT
from the kind label (blocker 1). Each lane declares a signature [da, ret]: da = double
value ARGS, ret = the return transform (none | idv | sum | min | max). A per-kind rule
then decides whether each crossing value is a Smi: an arg / idv return is Smi for int
and p30 (both < 2^31); a SUM return overflows Smi even on p30 (a range of ~2^30 values)
and stays Smi only for int; a MIN return is non-Smi for p31 (2^31) / n31 (<< -2^31) /
p53 / frac; a MAX return is a Smi for n31 (max = -2^31) and p30 (< 2^31) but non-Smi
for p31 / p53 / frac. So e.g. Fenwick2D.rectSum on p30 is k=1 (sum return, GREEN B),
and SortedArray.max / MinMaxHeap.peekMaxKey on n31 are k=0 (Smi max, ZERO). k is also
counted PER SHARD: a value RETURN from a call that also takes a double ARG is consumed
inline in a NORMAL shard, so successor / predecessor cross 1 box normal (k=1) but 2
under ni- (k=2).
Budget: k=0 is the ROADMAP ZERO = 2 (any box on a clean path fails, incl. a half-box
~6 or a third-box ~4); k>=1 is floor((k + 0.5) * B1) (B1 = 12), so k1 -> 18, k2 -> 30,
and box k+1 ALWAYS fails (the old 1.5*k*B1 let a k=2 carry three boxes; floor(0.5*B1)=6
let a half-box pass on a k=0 path). Every clean k=0 cell reads 0, so ZERO=2 costs nothing.
In the NORMAL shard the DEFAULT is k=0: a lane earns the k-budget only by declaring
itself a boundary box (the central BOUNDARY set, whose entries must actually box > 0 in
the normal shard -- a stale entry FAILS the shard), so a new lane cannot silently get
the looser budget and a one-box regression on an inlined path fails. In the ni- shard
every lane gets the k-budget. A boundary-only (B) lane reads <= k boxes and PASSES; a
library-internal (A) defect reads >> k and FAILS.
